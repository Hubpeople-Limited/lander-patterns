Behaviour bundle

The JavaScript half of the pattern library, served as an ES module. Markup opts in with data-hub-module attributes, which do nothing until this file is on the page.

Current release

1.6.0, 21,234 bytes minified.

For a page the platform serves

The floating URL for the major. Each release repoints it, so a fix arrives without the page being rebuilt.

<script type="module"
        src="/hub-behaviours/v1/hub.min.js"></script>

For a site that holds a version still

Immutable, so it can carry an integrity hash. A module script is fetched cross-origin, which is what the crossorigin attribute is for.

<script type="module" crossorigin="anonymous"
        src="/hub-behaviours/1.6.0/hub.min.js"
        integrity="sha384-nU3h0DmfL5XNcZVIvp6miD9g9L0De3C1cfAowwUTUCmpCMZkYId/IlZqcajmbJos"></script>

Every version

manifest.json lists each published version with its integrity hash and the date it was first served.
