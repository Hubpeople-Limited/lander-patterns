# locations-landing@1

Generated by `ci/compose.py` from `ci/page-recipes.json` - never hand-edit; change the source and regenerate.

A **locations-landing** page shell. The index above a set of location pages. Rows rather than cards, because a place has no photograph of its own that is honest to use, and because the set grows: a brand adds a region and adds a row. It exists so a set of location pages is a structure with a parent rather than a run of pages reachable only from a search result.

Fetch `page.html` and `page.css`, write real copy into the slots, duplicate whatever block a pattern's comments say to duplicate, strip every comment, and keep each `{{ }}` token exactly as found - the platform fills those.

## Wiring

The brand's stylesheet loads first: link the brand's own `global.css` - its token values, per [TOKENS.md](../../TOKENS.md) - ahead of `page.css`, or merge `page.css` into it unchanged. `page.css` carries only the patterns' rules and reads every colour, radius and font from the brand's tokens.

The page carries its own site footer: this shell closes with the `colophon` pattern, and the platform fills its legal links and footer menu at serve time - keep every `{{ }}` token in it exactly as found. A site header is likewise a pattern a page carries (`masthead-nav` in this library); this composition ships without one.
