# Compositions

Pre-assembled page shells - generated by `ci/compose.py` from `ci/page-recipes.json`, never hand-edited.
Fetch one folder, write real copy into its slots, strip the comments, done - instead of assembling patterns by hand.

- **homepage-conversion@2** - homepage - hero-split -> steps-plain -> faq-details -> cta-band -> colophon - Opener, how it works, the questions, the ask - the ordinary conversion homepage.
- **homepage-no-photography@2** - homepage - hero-stated:ground=deep -> heading-block -> benefit-tiles -> cta-band -> colophon - The homepage for a brand with no photography. heading-block is not decoration here: benefit-tiles opens at h3 and says so in its own markup, so without an h2 above it the page skips a heading level.
- **pricing@2** - pricing - hero-stated:ground=plain -> pricing-tiers -> faq-details -> cta-band -> colophon - State the offer, show the tiers, answer the objection, ask.
- **safety@2** - safety - hero-stated:ground=brand -> safety-protections -> cta-band -> colophon - On a dating brand this is a conversion page in disguise, so it closes like one.
